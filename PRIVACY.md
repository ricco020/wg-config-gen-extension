# Privacy policy: Config Generator for WireGuard (Chrome extension)

Last updated: 30 October 2026. Publisher: VPNSmith (vpnsmith.com).

- The extension collects **no data**. It has **no permissions** and makes **no network requests**.
- Keys are generated in your browser with the Web Crypto API (X25519) and random bytes from `crypto.getRandomValues`. They exist only in the popup's memory and in the files you choose to copy or download. Closing the popup erases them.
- Nothing is stored, logged, synced or sent: no analytics, no tracking, no account.
- The popup contains links to vpnsmith.com (a setup guide and a full web generator, tagged with `utm_` parameters that say the visit came from the extension) and one affiliate link to a VPS provider. These pages open only when you click them; their own privacy policy then applies.
