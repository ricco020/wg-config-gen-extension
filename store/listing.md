# Chrome Web Store listing (EN)

Category: Developer tools. Language: English.

## Summary (manifest, 132 max)
Generate WireGuard server and client .conf files with keys created on your device. No account, no upload, no permissions.

## Description
Build a working WireGuard setup in under a minute, without pasting private keys into a website.

WHAT IT DOES
- Generates the server file (wg0.conf) and 1 to 10 client files in one click.
- Keys are created inside your browser (Web Crypto X25519). Optional preshared key per client.
- Fills addresses from your subnet (10.8.0.0/24 by default), listen port, client DNS (Cloudflare, Quad9, AdGuard or your own resolver).
- Full tunnel (all traffic) or split tunnel (VPN subnet only).
- Server file includes NAT and forwarding lines with comments, ready for wg-quick.
- Copy or download each .conf file.

PRIVACY
- No permissions, no network requests, no analytics, no account.
- Keys live only in the popup. Close it and they are gone, so download your files first.

NEED A SERVER?
The popup links to a step-by-step self-hosting guide on vpnsmith.com and to a VPS provider we use (affiliate link, disclosed in the popup). For QR codes to scan from a phone, use the full generator on vpnsmith.com.
